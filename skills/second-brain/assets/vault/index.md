# Second brain

Welcome. This is your second brain: put things in, dig them up later, ask questions about them.

## Put something in

- **Quick:** Mission Centre `[BR]` > `[D] Deposit`: type or paste, or drag a file into the window. It lands in
  [[_inbox/README|the inbox]].
- **In Obsidian:** a new note goes to `_inbox/` by default. Write anything.
- **With an agent:** in Claude Code or pi, say *"onthou dit: ..."* or *"stoor hierdie artikel in my brein"*.
  The `second-brain` skill files it, links it and logs it.

## Get something out

- Mission Centre `[BR]` > `[A] Ask`: *"Wat het ek oor ... gestoor?"*, *"What did I decide about ...?"*
- In Obsidian: search with `Cmd+Shift+F` (Mac) or `Ctrl+Shift+F` (Windows), or open the graph view.
- Recent deposits: [[log]].

## Keep it tidy

- `[BR]` > `[P] Process inbox` files everything in the inbox into proper notes.
- Rules for this vault: [[BRAIN]].

## Folders

`notes/` ideas and facts · `sources/` articles, books, videos · `people/` · `projects/` · `journal/` daily notes ·
`answers/` kept answers · `_attachments/` original files · `_archive/` old captures
